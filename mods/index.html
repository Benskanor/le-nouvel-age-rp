Direction du projet

Une sélection guidée par quatre principes

  1. 01Cohérence

    Chaque ajout doit soutenir l’univers médiéval-fantastique et ses civilisations.

  2. 02Lisibilité

    Les systèmes restent compréhensibles pour les nouveaux joueurs.

  3. 03Stabilité

    Les versions sont testées avant d’entrer dans la configuration active.

  4. 04Utilité RP

    Une extension doit créer des histoires, des métiers ou de nouveaux usages.
