# Wiki V1 — Le Nouvel Âge RP

Cette archive inclut aussi les fichiers Personnages V3.2 afin de ne perdre aucune correction précédente.

## Installation
1. Décompresser le ZIP.
2. GitHub Desktop → Repository → Show in Explorer.
3. Copier tout le contenu du ZIP à la racine du dépôt `le-nouvel-age-rp`.
4. Accepter la fusion/remplacement des fichiers.
5. Commit : `Ajout du Wiki officiel V1`.
6. Push origin.
7. Cloudflare Pages redéploiera automatiquement.
