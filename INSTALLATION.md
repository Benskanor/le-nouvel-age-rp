# Installation — Registre des personnages V3

Cette mise à jour remplace uniquement 5 fichiers :

- `personnages/index.html`
- `assets/css/personnages.css`
- `assets/js/personnages.js`
- `data/personnages.json`
- `data/layout.json`

## Installation
1. Ouvrir le dépôt `le-nouvel-age-rp` dans GitHub Desktop.
2. `Repository > Show in Explorer`.
3. Copier les dossiers du ZIP à la racine du dépôt.
4. Accepter la fusion des dossiers et le remplacement de ces 5 fichiers.
5. Commit : `Refonte finale de la page Personnages`.
6. `Push origin`.
7. Cloudflare Pages republie automatiquement le site.

La page est accessible à `/personnages/`. Le lien `Personnages` est ajouté au menu principal de l'accueil par `data/layout.json`.
